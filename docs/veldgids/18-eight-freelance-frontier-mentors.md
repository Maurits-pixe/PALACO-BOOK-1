# Block 18 — Eight Freelance Frontier Mentors

Freelance mentors F01–F08 are on-demand specialist slots.

## Design
The slots are model-agnostic. A current frontier model can be bound to a slot without changing the constitutional interface.

| Slot | Primary specialization |
|---|---|
| F01 | Frontier Psychology |
| F02 | Frontier Neuroscience |
| F03 | Frontier Clinical Evidence |
| F04 | Frontier Research |
| F05 | Frontier AI & Cognition |
| F06 | Frontier Behavioral Science |
| F07 | Frontier Ethics & Safety |
| F08 | Frontier Synthesis / Red Team |

## Runtime rule
The Mentor Meester may activate a freelance slot when the permanent council lacks sufficient coverage or when independent review is required.

The registry records model provider, model identifier, capability snapshot, effective time, evaluation status and provenance.

No claim of "most powerful model available" is hard-coded; capability is measured through the platform's evaluation layer.
