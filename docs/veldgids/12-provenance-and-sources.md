# Block 12 — Sources & Provenance

## Canonical rule
NO KNOWLEDGE WITHOUT PROVENANCE.

Every Knowledge Object must be able to answer:
- Where did this information come from?
- What was the original artifact?
- What transformations occurred?
- Who or what created each transformation?
- Which version was used?

## Provenance chain
SOURCE -> EXTRACTION -> TRANSFORMATION -> KNOWLEDGE_OBJECT -> AI_ANALYSIS -> HUMAN_REVIEW

## Provenance states
UNKNOWN
PARTIAL
TRACEABLE
VERIFIED
REVOKED

VERIFIED means the provenance chain is complete enough for the defined use; it does not mean the substantive claim is universally true.

## AI attribution
AI-generated summaries, classifications and hypotheses are explicitly marked as derived material and never silently represented as source facts.
