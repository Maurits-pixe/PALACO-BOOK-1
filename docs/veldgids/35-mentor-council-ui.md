# Block 35 — Mentor Council UI / 3D Foundation

The Mentor Council UI is the visual operating surface for multi-mentor reasoning.

## Core views
1. Council overview
2. Mentor profile
3. Active routing plan
4. Parallel analyses
5. Consensus/dissent
6. Evidence panel
7. Uncertainty and escalation
8. Final synthesis

## 3D foundation
A future Three.js/WebGL layer may visualize mentors as spatial nodes around the Mentor Meester. The 3D representation is a presentation layer, not a source of authority.

## Accessibility
Every 3D state must have a complete 2D equivalent. Motion must be optional and reduced-motion settings respected.

## VORM9EVING
The visual layer may use the PALACO VORM9EVING principle: form communicates structure, provenance, state, and relation without implying authority that the underlying data does not possess.
