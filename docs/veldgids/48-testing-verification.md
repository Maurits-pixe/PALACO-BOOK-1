# Block 48 — Testing & Verification

Verification covers domain invariants, contracts, security, provenance, safety and runtime behavior.

## Test layers
- unit
- contract
- integration
- end-to-end
- migration
- authorization
- provenance
- safety
- load/resilience

A green test suite is evidence about the tested configuration; it does not authorize untested behavior.

Release candidates retain commit, dependency, configuration, test and artifact provenance.
