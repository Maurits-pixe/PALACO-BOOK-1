# Block 34 — Report Generator

Report Generator converts approved knowledge and analysis artifacts into structured reports.

## Pipeline
`COLLECT -> VALIDATE -> STRUCTURE -> CITE -> REVIEW -> RENDER -> SEAL`

## Report sections
- scope
- executive summary
- evidence
- mentor analyses
- consensus and dissent
- uncertainty
- conclusions or options
- sources
- provenance
- review status

## Output formats
The renderer may support HTML, Markdown, PDF, and machine-readable JSON.

## Rule
A generated report is not authoritative merely because it is rendered or sealed. Publication status and human authorization remain explicit.
