# Block 23 — Evidence-Aware Responses

Every consequential response should distinguish its evidentiary basis.

## Response layers
1. User context
2. Source evidence
3. Mentor analyses
4. Synthesis
5. Uncertainty
6. Suggested next steps
7. Provenance

The interface should allow the user to inspect the supporting sources and the reasoning contributions without exposing private chain-of-thought.

The system may provide concise rationales, evidence summaries and explicit uncertainty instead of hidden internal reasoning traces.
