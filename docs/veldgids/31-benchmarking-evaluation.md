# Block 31 — Benchmarking & Evaluation

Benchmarking evaluates mentors, prompts, workflows, and model bindings under explicit test conditions.

## Evaluation record
- evaluation_id
- subject_type
- subject_id
- subject_version
- dataset_id
- test_configuration
- metrics
- safety_checks
- evaluator
- created_at
- provenance

## Principles
No single score is treated as universal truth. Results are contextual to the dataset, task, model binding, prompt version, and evaluation configuration.

## Model binding
Frontier mentor slots remain model-agnostic. A new model binding becomes active only through the defined registry and evaluation process.
