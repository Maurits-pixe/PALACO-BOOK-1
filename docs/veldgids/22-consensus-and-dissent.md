# Block 22 — Consensus & Dissent

Agreement is evidence about agreement, not proof of truth.

The synthesis layer therefore preserves:
- consensus
- material disagreement
- minority analysis
- unresolved uncertainty
- evidence conflicts

## Consensus record
CONSENSUS_ID
PARTICIPATING_MENTORS
AGREED_CLAIMS
DISPUTED_CLAIMS
EVIDENCE_CONFLICTS
UNRESOLVED_QUESTIONS
SYNTHESIS_VERSION

No numerical "wisdom score" or mentor ranking is required for the first release.
