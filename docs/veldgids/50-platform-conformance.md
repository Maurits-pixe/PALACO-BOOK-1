# Block 50 — Platform Conformance

Blocks 1–50 form a coherent platform contract.

## Conformance principles
- USER remains decision authority.
- AI remains advisory and evidence-aware.
- Authentication != authorization.
- Source != extraction != analysis != conclusion.
- Published artifacts are versioned.
- Provenance is retained across transformations.
- Dissent is preserved.
- External side effects require authorization.
- Observability is not authority.
- 3D is presentation, never governance.

## Completion criterion
The platform is conformant only when these principles are represented in executable contracts, tests, runtime controls, and auditable evidence—not merely documentation.
