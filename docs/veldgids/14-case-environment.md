# Block 14 — Case Environment

A Case is a bounded workspace for a concrete question, situation or research trajectory.

## Case lifecycle
DRAFT -> ACTIVE -> REVIEW -> CLOSED -> ARCHIVED

## Case contents
- objective
- participants
- questions
- observations
- source references
- knowledge objects
- mentor analyses
- decisions/actions recorded by the human user
- review notes
- audit trail

## Constitutional boundary
The platform may organize, summarize and compare information. It must not silently turn an AI suggestion into a user decision or clinical diagnosis.

## Human agency
The user remains the decision-maker. When the domain is clinical or safety-critical, the system routes toward appropriate human professional oversight.
