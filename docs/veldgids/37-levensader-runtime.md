# Block 37 — De Levensader Runtime

De Levensader is the canonical knowledge access layer.

## Flow
SOURCE -> INGEST -> EXTRACT -> CLASSIFY -> INDEX -> RELATE -> REVIEW -> PUBLISH

## Runtime guarantees
- source artifacts remain immutable
- published knowledge is versioned
- provenance accompanies consequential retrieval
- revoked material generates review signals
- retrieval never silently changes canonical knowledge

Search and retrieval are read operations; publication remains governed.
