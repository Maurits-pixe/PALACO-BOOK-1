# Block 43 — Security & Privacy

Security is enforced at every trust boundary.

## Controls
- least privilege
- encryption in transit and at rest
- secret isolation
- input validation
- rate limiting
- audit logging
- retention/deletion policy
- sensitive-data classification
- tenant/context isolation
- dependency and supply-chain review

Mental-health and other sensitive information receives explicit access control and purpose limitation.

Security telemetry is evidence for operations, not a substitute for authorization.
