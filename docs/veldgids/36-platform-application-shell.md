# Block 36 — Platform Application Shell

The web application is the operational shell for De Mentale Veldgids.

## Surfaces
- Dashboard
- Levensader
- Library
- Cases
- People & Organizations
- Mentor Council
- AI Studio
- Academy
- Research Lab
- Reports
- Observatory
- Administration

Navigation is role-aware. Authentication never implies authorization.

## State
The shell consumes versioned API contracts and must not duplicate domain authority in client state.
