# Block 32 — AI Observatory

AI Observatory provides operational visibility over the AI system.

## Observables
- active model bindings
- prompt versions
- workflow versions
- mentor routing
- latency
- token/cost telemetry
- error rates
- safety events
- provenance gaps
- human escalation events

## Rule
Observability data is evidence about system operation, not hidden authorization.

Sensitive telemetry follows least-privilege access and retention policy.
